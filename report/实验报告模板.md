## 1. 任务背景与问题描述

### 1.1 任务介绍

小学数学应用题自动解题是衡量机器学习模型在应用题理解方面能力的重要任务。该任务要求模型读入一个应用题，输出该题的结果（数字答案）。

**任务特点**：
- 题目为小学数学1-6年级校内题目
- 输出为纯数字答案（不带单位）
- 评估指标为正确率（accuracy）

### 1.2 数据集说明

- **训练集**：train.json，包含12,000条训练数据
- **测试集**：test.json，包含8,000条测试数据
- **数据格式**：
  ```json
  {
    "id": "0",
    "question": "食堂运来105千克的萝卜...",
    "answer": "315",
    "instruction": "这是小学数学1-6年级的校内题目..."
  }
  ```

### 1.3 约束条件

- **模型限制**：仅允许使用0.5B及更小参数模型（推荐Qwen2.5-0.5B）
- **数据约束**：严禁处理/修改测试数据
- **提交格式**：CSV文件，包含id和ret两列

## 2. 方案设计与实现

### 2.1 Baseline方案

#### 2.1.1 方法描述

Baseline方案采用基于LoRA的PEFT（参数高效微调）方法对Qwen2.5-0.5B进行微调：

- **基础模型**：Qwen/Qwen2.5-0.5B-Instruct
- **微调方法**：LoRA（Low-Rank Adaptation）
- **LoRA配置**：
  - r=8（LoRA秩）
  - lora_alpha=32
  - lora_dropout=0.1
  - target_modules：q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj

#### 2.1.2 训练配置

| 参数 | 值 |
|------|-----|
| 学习率 | 1e-4 |
| batch_size | 4 |
| gradient_accumulation_steps | 4 |
| num_epochs | 5 |
| max_length | 384 |
| 优化器 | AdamW |

### 2.2 方案1：COT优化

#### 2.2.1 方法描述

COT（Chain of Thought，思维链）优化通过改进提示词来激活模型的推理能力，无需额外训练。本方案对比了以下提示方式：

1. **Standard**：标准提示，直接输出答案
2. **Zero-shot COT Simple**：简单零样本COT（"Let's think step by step"）
3. **Zero-shot COT**：详细零样本COT（分步骤提示）
4. **Few-shot COT**：提供示例引导模型推理

#### 2.2.2 提示模板示例

**Zero-shot COT提示**：
```
这是小学数学1-6年级的校内题目，请按照以下步骤解答：
1. 理解题目要求
2. 列出已知条件
3. 分析解题思路
4. 逐步计算
5. 给出最终答案（仅数字，不带单位）
```

**Few-shot COT提示**：
```
示例1：
题目：商店有4框苹果，每框55千克，已经卖出135千克，还剩多少千克苹果？
解答：
1. 首先计算总共有多少千克苹果：4 × 55 = 220千克
2. 然后减去已经卖出的：220 - 135 = 85千克
3. 所以还剩85千克
答案：85

[更多示例...]

现在请解答下面的题目：
```

### 2.3 方案2：数据构建与增强

#### 2.3.1 方法描述

本方案通过以下方式改进训练数据：

1. **COT数据生成**：为训练数据补充完整的解题步骤
2. **数据增强**：通过数字替换合成新的训练样本

**COT数据生成方法**：
- 使用模板为每个训练样本生成解题步骤
- 将COT步骤与答案结合作为训练目标

**数据增强方法**：
- 识别题目中的数字
- 通过随机因子生成新的数字组合
- 生成新的训练样本

#### 2.3.2 数据示例

**原始数据**：
```json
{
  "question": "商店有4框苹果，每框55千克...",
  "answer": "85"
}
```

**带COT的数据**：
```json
{
  "question": "商店有4框苹果，每框55千克...",
  "cot": "解题步骤：\n1. 首先计算总共有多少千克苹果：4 × 55 = 220千克\n2. 然后减去已经卖出的：220 - 135 = 85千克\n3. 所以还剩85千克",
  "answer": "85"
}
```

#### 2.3.3 训练配置

与Baseline相同，但：
- 使用带COT的数据进行训练
- max_length增加到512（COT步骤较长）
